# Orkeed Clothes ERP — نظام إدارة محلات الملابس المتكامل

نظام نقاط بيع (POS) وإدارة مخازن وحسابات متكامل مصمم خصيصاً لمحلات ومتاجر الملابس، يعمل بنظام **Offline-First** (يعمل بكفاءة كاملة بدون إنترنت) مع قاعدة بيانات محلية SQLite عبر Drift، ودعم كامل للغة العربية (RTL) وخط Cairo.

---

## ✨ أبرز المميزات (Core Features)

### 🛒 نقطة البيع (POS)
- **دعم قارئ الباركود الفعلي (Hardware Keyboard Listener):** استماع تلقائي على مستوى الشاشة مع تركيز تلقائي (Autofocus) لإضافة المنتجات فوراً بمجرد المسح.
- **شبكة منتجات مدمجة وسريعة (Compact POS Grid):** كروت منتجات صغيرة وبسيطة تعرض عشرات الأصناف في الشاشة الواحدة مع إضافة فورية بالنقر المباشر على الكارت وأزرار دفع منسقة في صف واحد.
- **مصفوفة الألوان والمقاسات:** اختيار سريع للمنتج بالمقاس واللون مع عرض الرصيد المتاح.
- **الدفع المجزأ (Split Payments):** إمكانية تقسيم الفاتورة بين النقدي (كاش) والبطاقة (فيزا) والمحافظ الإلكترونية.
- **البيع بالتقسيط المباشر:** إنشاء عقود تقسيط مباشرة من شاشة الكاشير مع ربط المقدم بدرج النقدية.
- **محرك العروض والخصومات (Promotions Engine):** دعم خصومات الأصناف، النسب المئوية، والخصومات التلقائية.
- **طباعة الفواتير والإيصالات الحرارية.**

### 📦 إدارة المنتجات والمخازن
- **منع تكرار المنتجات والأكواد (SKU) والبحث الذكي بالتشابه:**
  - تطبيع ذكي للنصوص العربية (توحيد الهمزات أ/إ/آ -> ا، الياء ى -> ي، التاء المربوطة ة -> ه، وإزالة التشكيل والمسافات الزائدة).
  - تنبيه فوري وعرض المنتجات المتشابهة أثناء الكتابة في شاشة إضافة المنتج.
  - منع تام لحفظ أي منتج مكرر أو كود (`SKU`) مكرر (بدون حساسية لحالة الأحرف أو المسافات) على مستوى الواجهة والجدول وقاعدة البيانات.
- **طباعة ملصقات الباركود (Barcode Label Printing):** دعم الطباعة الحرارية (Roll 50×30mm و 38×25mm) وورق A4.
- **مسار موحد لحركة المخزون (`applyStockMovement`):** كل حركة بيع، مرتجع، شراء، أو تسوية تُسجل آلياً في `inventory_logs`.

### 💳 نظام الأقساط والتحصيل (Installments)
- **تجميع الأقساط حسب العميل:** عرض كل عميل بملخص إجمالي مديونيته وعقوده النشطة والمتأخرة.
- **السداد المجمع السريع بنظام FIFO:**
  - حقل إدخال مباشر بجوار اسم العميل لكتابة المبلغ المدفوع بدلاً من الدخول لكل عقد منفرداً.
  - توزيع تلقائي ذكي للمبلغ بنظام الأقدم فالأحدث (**FIFO**) حتى نفاد المبلغ أو سداد العقود بالكامل.
  - منع إدخال مبلغ أكبر من إجمالي مديونية العميل.
  - مزامنة فورية لكل دفعة مع درج النقدية (`cash_movements`) والوردية المفتوحة (`shiftId`).
- **حماية الرقم السري للمدير (Manager PIN Protection)** مع نظام قفل مؤقت عند المحاولات الخاطئة.

### 🚚 المشتريات والموردين
- فواتير المشتريات واستلام البضائع مع تحديث تلقائي للمخزون.
- **مرتجعات المشتريات للموردين (Supplier Purchase Returns):** خصم فوري من المخزون، تسجيل في `inventory_logs`، تسوية رصيد المورد، واسترداد النقدية للدرج.
- سداد مدفوعات الموردين بنظام FIFO.

### 💰 الورديات والدرج ولوحة التحكم (Shifts & Executive Dashboard)
- **لوحة تحكم تنفيذية متطورة (Executive Dashboard):** مؤشرات الأداء اليومية والشهرية، صافي الربح، المبيعات، الأقساط المحصلة، تنبيهات النواقص، وأكثر الأصناف مبيعاً.
- **إدارة الورديات (Shifts):** فتح وإغلاق الوردية، مطابقة النقدية الفعلية مع المتوقعة، وعرض تفصيلي لتحصيل الأقساط والمرتجعات والمصروفات داخل الوردية.
- إدارة الموظفين والرواتب والسلف والمكافآت.
- نظام صلاحيات (Admin / Manager / Cashier) وبوابة ميزات (`FeatureGate`).

### 🎨 تخصيص الهوية والألوان والتنقل (Branding & Layout)
- **تخصيص اسم وألوان النظام من إعدادات الأدمن:** تغيير اسم النظام (الافتراضي: `سيستم مبيعات`) واللون الأساسي والثانوي عبر 8 قوالب جاهزة أو أكواد Hex مخصصة مع تطبيق فوري على كافة شاشات النظام والقائمة الجانبية والباركود والإيصالات.
- **قائمة جانبية ثابتة لجميع الشاشات (Nested MainLayout):** جميع الشاشات والصفحات الفرعية تُعرض داخل اللايوت الرئيسي مع إبقاء السايد بار ظاهراً، باستثناء شاشة نقطة البيع (الكاشير) التي تفتح بملء الشاشة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Framework:** Flutter (Windows Desktop Primary Target)
- **Local Database:** Drift (SQLite) — Offline-First with Atomic Transactions (`TxWriter`)
- **State Management:** `flutter_bloc` (Bloc / Cubit)
- **Dependency Injection:** `get_it` + `injectable`
- **Functional Error Handling:** `dartz` (`Either<Failure, T>`)
- **Printing & PDF:** `pdf`, `printing`, `barcode`
