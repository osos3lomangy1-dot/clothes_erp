# Bay3ah ERP (بيعة) — نظام إدارة نقاط البيع والمخازن والحسابات المتكامل

**Bay3ah ERP (بيعة)** هو نظام تجاري متكامل لإدارة نقاط البيع (POS)، المخازن، الأقساط، المشتريات، الموردين، والمالية. مصمم خصيصاً للمحلات والمتاجر التجارية بنظام **Offline-First** (يعمل بكفاءة 100% دون الحاجة لأي اتصال بالإنترنت)، مع قاعدة بيانات محلية SQLite فائقة السرعة والأمان عبر Drift، ودعم أصلي لنظام التشغيل **Windows Desktop**، واللغة العربية بالكامل (RTL) مع خط Cairo.

> **المعرف الداخلي للمستودع:** `clothes_erp`  
> **اسم الملف التنفيذي التجاري:** `bay3ah.exe`  
> **حالة الجودة الهندسية:** **581 اختباراً ناجحاً بنسبة 100%** | **0 أخطاء و 0 تحذيرات في `flutter analyze`**  
> **محرك قواعد البيانات النشط:** SQLite `3.53.4` بنمط `WAL` و `Single Transaction Migration`

## ✨ المميزات الرئيسية للمنظومة (Core System Features)

### 🛒 1. نقطة البيع السريعة (High-Performance POS)
- **دعم كامل لقارئ الباركود الفعلي (Hardware Keyboard Listener):** استماع تلقائي على مستوى الشاشة مع تركيز ذكي (Autofocus) لإضافة المنتجات فورياً دون الحاجة للنقر بالفأرة.
- **شبكة أصناف مدمجة (Compact POS Grid):** عرض عشرات الأصناف في واجهة مريحة ومضغوطة تناسب شاشات اللمس وشاشات الكمبيوتر، مع دعم نمطي العرض (كروت شبكية / جدول تفصيلي).
- **مصفوفة الألوان والمقاسات (Variants Matrix):** دعم الأصناف ذات المقاسات والألوان المتعددة مع عرض فوري للرصيد المتاح لكل مقاس ولون.
- **طرق الدفع المتعددة والمجزأة (Split Payments):** إمكانية دفع الفاتورة الواحدة بأكثر من وسيلة (نقدي، بطاقة/فيزا، إنستاباي، محافظ إلكترونية، آجل، تقسيط).
- **محرك الخصومات والعروض (Promotions Engine):** خصومات نسبية ومبالغ ثابتة، عروض اشترِ واحصل على آخر (BOGO)، وخصومات الأصناف أو التصنيفات.
- **طباعة الفواتير والإيصالات الحرارية (Thermal POS Receipts):** دعم الطابعات الحرارية (80mm و 57mm) مع تفقيط المبالغ، وتضمين تفاصيل طرق الدفع وشروط الاستبدال والاسترجاع.
- **متانة الفاتورة عند انقطاع الكهرباء (Checkout Durability):** تدفق ذري لبيانات الفاتورة المطبوعة مباشرة إلى القرص عبر `PRAGMA wal_checkpoint(PASSIVE)` فور اكتمال الدفع لضمان عدم ضياع أي فاتورة في حال انقطاع الطاقة المفاجئ.

### 📦 2. إدارة المخازن والمنتجات والباركود (Inventory & Barcodes)
- **منع تكرار المنتجات والأكواد (Anti-Duplicate & Real-Time Warning):**
  - تطبيع آلي للنصوص العربية (`ArabicTextHelper`): توحيد الهمزات (أ/إ/آ -> ا)، الياء (ى -> ي)، التاء المربوطة (ة -> ه)، وحذف التشكيل والمسافات الزائدة.
  - تنبيه فوري بالمنتجات المتشابهة أثناء كتابة الاسم، مع حاجز تأكيد لمنع الخطأ البشري.
  - منع قاطع لحفظ أي منتج مكرر أو باركود (`SKU`) مكرر على مستوى الواجهة وقاعدة البيانات.
- **طباعة ملصقات الباركود (Barcode Label Printing):** دعم الطباعة الحرارية للرول (50×30mm و 38×25mm) بالإضافة لورق A4 متعدد الملصقات.
- **المسار الموحد لحركة المخزون (`applyStockMovement`):** توثيق كل حركة إضافة، بيع، مرتجع، هالك، أو شراء داخل جدول سجلات المخزون `inventory_logs` كمرجع تدقيقي وحيد.

### 💳 3. نظام الأقساط والمتابعة الذكية (Installments Module)
- **شاشة تجميع العملاء (Grouped Customer View):** عرض رصيد كل عميل، إجمالي مديونيته، والعقود النشطة والمتأخرة بدقة متناهية.
- **السداد المجمع السريع بنظام الأقدم فالأحدث (Bulk FIFO Payment):**
  - سداد فوري بضغطة واحدة من الشاشة الرئيسية دون الحاجة للدخول في تفاصيل كل قسط.
  - توزيع ذكي للمبلغ المدفوع على الأقساط الأقدم فالأحدث حتى استيفاء المبلغ.
  - منع إدخال مبالغ تتجاوز مديونية العميل.
  - ربط السداد بدرج النقدية والوردية المفتوحة آلياً.
- **حماية رمز الأمان للإدارة (Manager PIN):** قفل عمليات جدولة وتعديل الأقساط وحمايتها بكلمة سر المدير مع نظام قفل مؤقت عند المحاولات الخاطئة.

### 🚚 4. المشتريات والموردين (Purchases & Suppliers)
- فواتير مشتريات واستلام بضائع مع تحديث فوري للمخزون والتكلفة.
- **مرتجعات المشتريات (Supplier Purchase Returns):** خصم فوري للبضاعة المرتجعة، تسجيل أثر المخزون في `inventory_logs`، تسوية حساب المورد، واسترداد النقدية للدرج.
- سداد دفعات الموردين بنظام FIFO.

### 💰 5. الورديات والخزينة ولوحة التحكم (Shifts & Cash Management)
- **إدارة الورديات (Shift Cycles):** فتح الوردية برصيد افتتاحي، مطابقة النقدية الفعلية مع المتوقعة عند الإغلاق، وحساب العجز أو الزيادة تلقائياً.
- **تتبع حركات الخزينة (`cash_movements`):** توثيق تدفقات المبيعات، المرتجعات، المصروفات، سلف الموظفين، وتحصيل الأقساط.
- **لوحة التحكم التنفيذية (Executive Dashboard):** مؤشرات فورية للأداء اليومي والشهري، صافي الأرباح، المبيعات حسب الساعات، وتنبيهات النواقص.

### 🛡️ 6. منظومة أمان الترقية وقواعد البيانات (Upgrade Safety Engine)
- **المعاملة الواحدة الشاملة (Single Migration Transaction):** تنفيذ ترقيات الشيما بالكامل داخل معاملة واحدة تضمن التراجع الذاتي الكامل (ACID Rollback) في حال حدوث أي خطأ أو انقطاع مفاجئ.
- **انعدام نافذة الخطر بعد الاعتماد (Zero Post-Commit Window):** دمج تحديث `PRAGMA user_version` داخل المعاملة ليتم اعتماده ذرياً في نفس الفريم مع تغييرات الجداول.
- **مؤشر الترقية الذري (Migration Marker Service):** تسجيل خطوات الترقية بملف ذري يُستبدل على Windows عبر `File.rename` المباشر دون أي ثغرة اختفاء للملف.
- **النسخ الاحتياطي الذري المتسق (`VACUUM INTO`):** أخذ نسخة كاملة ومستقلة بقاعدة مفتوحة دون أي أقفال ملفات Windows، مع فحص سلامة هيكلية `PRAGMA quick_check` ومطابقة الهاش القانوني الصارم `canonical SHA-256`.
- **شاشة الطوارئ والاسترجاع المحمي (Emergency Recovery Screen):** واجهة مستخدم خاصة تظهر تلقائياً عند الإقلاع في حال رصد تعثر في فتح القاعدة أو ترقية معلقة، تتيح للمدير الاسترجاع الآمن برقم سري وتصدير تقرير تشخيصي مشفر خالي تماماً من بيانات العملاء.

### 🎨 7. تخصيص الهوية والقطاعات (Branding & Sectors)
- **تخصيص كامل للهوية البصرية:** إمكانية تغيير اسم النظام وألوانه الأساسية والثانوية عبر 8 قوالب جاهزة أو أكواد ألوان مخصصة مع تطبيق فوري على كافة الشاشات والإيصالات.
- **دعم قطاعات التجزئة المتعددة:** ملابس وأحذية (مقاسات وألوان)، محلات تجزئة عامة وسوبرماركت (أصناف سريعة)، إلكترونيات وأجهزة (أرقام تسلسلية وضمان).
