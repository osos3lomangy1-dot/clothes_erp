## 📦 Distribute the Windows App

> [!IMPORTANT]
> ### ⚠️ Critical Prerequisite: Microsoft Visual C++ Redistributable (`MSVCP140.dll`)
> Flutter Windows apps are compiled with Microsoft Visual C++ and dynamically link against the C Runtime (`msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`).
> If a client machine does NOT have the **Visual C++ 2015–2022 Redistributable (x64)** installed, the app will crash immediately on startup with:
> `The code execution cannot proceed because MSVCP140.dll was not found.`
> 
> To prevent this crash permanently for all clients, use one of the 3 automated distribution methods below:

---

### Option A — Inno Setup Single-File Installer (Recommended for End Users)

The most professional and fool-proof method. It generates a single `Setup.exe` that:
1. Checks the Windows registry for `HKLM\SOFTWARE\Microsoft\VisualStudio\14.0\VC\Runtimes\x64`.
2. Automatically and silently installs `vc_redist.x64.exe` (`/install /quiet /norestart`) if missing.
3. Installs the app to `Program Files\Orkeed Clothes ERP`.
4. Creates Desktop & Start Menu shortcuts and a clean uninstaller.

**How to build locally:**
```bash
# 1. Build Flutter release
flutter build windows --release

# 2. (Optional) Download vc_redist.x64.exe into windows/installer for 100% offline bundling:
windows\installer\download_vc_redist.bat

# 3. Compile the installer with Inno Setup 6:
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" windows\installer\inno_setup.iss
# Output: build/installer/OrkeedClothesERP_Setup_v1.0.0.exe
```

**Via CI/CD:**
The GitHub Actions workflow builds this installer automatically and uploads it as `Orkeed-erp-setup-vX.Y.Z`.

---

### Option B — ZIP Distribution with Auto-Repair Launcher (`launch_app.bat`)

If you prefer distributing a portable `.zip` folder:
1. Every release ZIP generated by GitHub Actions automatically includes [`launch_app.bat`](file:///e:/flutter%20projects/erp%20systems/clothes_erp/windows/installer/launch_app.bat) alongside `clothes_erp.exe`.
2. Instruct the client to run **`launch_app.bat`**.
3. It automatically verifies if `msvcp140.dll` exists in `System32`. If missing, it downloads the official Microsoft `vc_redist.x64.exe`, installs it silently, and launches the ERP app without any manual steps or crashes.

---

### Option C — MSIX Installer (Windows Store / Sideloading)

MSIX is a modern Windows package format:
```bash
# After `flutter build windows --release`
dart run msix:create
# Output: build/windows/x64/runner/Release/clothes_erp.msix
```

> [!NOTE]
> MSIX packages cannot execute Win32 child installers (`vc_redist.x64.exe`) during installation.
> When sideloading on bare machines without the Microsoft Store, install the VC++ Redistributable or the `Microsoft.VCLibs.x64.14.00.Desktop.appx` dependency package first.

---

### 🌐 Manual Client Fix (Direct Link)
If any client already has an unzipped version and encounters the `MSVCP140.dll` error:
- Send them the official Microsoft x64 link:
  👉 **https://aka.ms/vs/17/release/vc_redist.x64.exe**
- Run it, click "Install", restart the app.

## 🛠 Common Issues

| Problem | Fix |
|---|---|
| Missing DI annotations | Ensure `@injectable` / `@lazySingleton` on new classes, then run `build_runner` |
| Drift `duplicate column` at runtime | Bump `schemaVersion` in `app_database.dart` and add `m.addColumn(...)` with PRAGMA guard |
| `flutter build windows --release` fails | Run `flutter doctor` and make sure Visual Studio 2022 (with C++ workload) is installed |
| MSIX install blocked | Trust the self-signed cert first (see Option B above) |
| Money precision errors | Always use `int` minor units (piasters), never `double` |
