# UI Design System

## Theme
- Primary: Purple 0xFF673AB7 (Material 3)
- Material 3 with light theme

## MainLayout
- Persistent collapsible Sidebar (left) + content area (right)
- Sidebar: dark purple surface, white icons/text, collapses to icons-only

## POS UI
- Split screen: left catalog (search + product cards), right cart
- Cart uses DataTable with columns: #, SKU, Item, Qty, Unit Price, Discount, Total, Action
- Editable price/discount per row via TextField
- Top action bar: held sales, close day, new sale
- Bottom footer: Grand Total + massive Checkout button
- Keyboard shortcuts: F2 search, F4 qty, F12 checkout

## Empty States
- "Cart is empty" with icon
- "No products found. Add products in the Products screen first."
